# Security Policy — Public Source Candidate

Status: **PREPARED — NOT YET PUBLISHED**

## Reporting

Do not publish credentials, private keys, customer data, transaction identifiers, or exploit details in a public issue.

When the clean-history public repository is created, use its private vulnerability-reporting/security-advisory channel when available. If that channel is not available, use a private contact method published by the project maintainer rather than disclosing sensitive material publicly.

## Scope

This source repository is intended to contain only the reviewed public-source implementation and non-commerce tests. Seller signing operations, commercial fulfillment, customer/transaction state, commercial build secrets, and private release operations are outside its scope.
