# Security Policy — Public Source

Status: **PUBLISHED**

## Reporting

Do not publish credentials, private keys, customer data, transaction identifiers, or exploit details in a public issue.

Use GitHub private vulnerability reporting/security advisories for this repository when available. If that channel is unavailable, use a private contact method published by the project maintainer rather than disclosing sensitive material publicly.

## Scope

This source repository contains only the reviewed public-source implementation and non-commerce tests. Seller signing operations, commercial fulfillment, customer/transaction state, commercial build secrets, and private release operations are outside its scope.
